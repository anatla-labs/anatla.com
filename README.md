# anatla.com

Holding page for Anatla. Plain HTML + CSS, no build step. Hosted on GitHub Pages from the `main` branch; the `CNAME` file pins the custom domain.

## Editing

- `index.html` – the page copy. The "Register your interest" link is the `mailto:` in the last paragraph; swap it for the form URL when the Brevo/MailerLite decision is made.
- `style.css` – layout, colours and the SVG line widths. Brand colours: woad `#5876d5`, peach `#fc7e49`, sienna `#c04729`, ink `#000`.
- `assets/logo.svg` – vector logo extracted from `Anatla_Logo_colour.pdf`. Uses `currentColor`, so recolour it with CSS.
- `assets/og.png` – social share image: a 1200×900 headless-Chrome screenshot of `index.html`. Retake it when the copy changes.

## Fonts

The copy is set in **ABC Arizona Flare** (Dinamo), bought Sep 2026 on a **desktop/print licence** (up to 3 people). That licence does not allow `@font-face`, converting to WOFF2, or putting the font files on a public server or in a public repo. So the four lines of copy are shipped as **SVG outlines**, generated by `tools/render_text.py` from the OTFs, which live outside the repo in `../fonts-private/` (with the licence PDF). `.gitignore` blocks font files as a backstop.

To change the copy: edit `COPY` in `tools/render_text.py`, run it (needs `pip install uharfbuzz fonttools`), commit the regenerated `index.html`. Also update the visually hidden text in `index.html` for search engines and screen readers.

If a future site needs live text in this font, buy a Dinamo **web licence** (one domain, no traffic limit) and switch to `@font-face`.

## Deploy

Push to `main`. GitHub Pages publishes the repo root directly; no Actions workflow needed.

Adding pages later: drop another `.html` file next to `index.html` and link to it. If the site grows past a handful of pages, move to Hugo.
